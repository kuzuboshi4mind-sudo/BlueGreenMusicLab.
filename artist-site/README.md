# 猪原 純 オフィシャルサイト

GitHub Pages で**無料**公開できる、軽量な静的サイトです。

| これまでの悩み | このサイトでの解決 |
|---|---|
| 年間約2万円の使用料 | GitHub Pages は無料（必要なのは独自ドメイン代 年1,500円前後のみ） |
| 更新が面倒 | スマホ／PCのブラウザからフォームで投稿（Pages CMS）。ファイル1つ追加でも可 |
| 過去ログが残らない | ニュースは年別アーカイブ、終わったライブは毎日自動で「Archive」へ移動。記事ごとに固定URL |
| SNSとの連携が難しい | SNSリンクを一括管理／記事ごとのシェアボタン／OGP（シェア時のカード表示）／RSSで自動投稿連携 |
| ページが重い | 外部ライブラリなし。YouTubeはクリックするまで読み込まない軽量埋め込み |

## ページ構成
- `/` トップ（直近のライブ3件・最新ニュース・Showreel・最新作）
- `/news/` ニュース（年ごとの過去ログ）
- `/live/` ライブ（予定／過去の公演を年別アーカイブ）
- `/movie/` 動画（Solo／屑星／THE FROGS／Feel Art Cafe で絞り込み）
- `/biography/` `/discography/` `/projects/` `/contact/`

## 更新のしかた

### 方法A：Pages CMS（おすすめ・フォーム入力）
1. https://app.pagescms.org に GitHub アカウントでログイン
2. このリポジトリを選ぶ → 左メニューに「ニュース」「ライブ」「Biography」「動画」「プロジェクト」「SNSリンク」「ディスコグラフィー」が出ます
3. 入力して保存 → 1〜2分でサイトに反映

### 方法B：GitHub で直接ファイルを追加
- ニュース：`_posts/2026-12-01-new-album.md`（ファイル名先頭が日付）
- ライブ：`_lives/2026-12-20-year-end.md`
- 書き方は同じフォルダのサンプルを参照

### 全体設定
- サイト名・肩書き・連絡先・トップの YouTube 動画：`_config.yml`
- SNS の URL：`_data/sns.yml`（空欄のものは表示されません）
- 動画：`_data/videos.yml` ／ プロジェクト：`_data/projects.yml`
- 画像：`assets/img/`（トップ `hero.webp`、プロフィール `profile.webp`、SNSシェア画像 `ogp.jpg`）。旧サイトから引き継いだもの。差し替えは同じファイル名で上書きすればOK

## お問い合わせフォーム（Web3Forms）
Googleフォームと違い、**送信内容はどこにも保存されず、直接メールに届く**だけなので容量が一杯になることがありません（無料・月250件まで）。メールアドレスもページ上に表示されないため、迷惑メール対策にもなります。
1. https://web3forms.com で受信したいメールアドレスを入力 →「Create Access Key」
2. メールで届いたアクセスキーを `_config.yml` の `web3forms_key:` に貼り付け
（未設定の間は「SNSのメッセージからご連絡ください」と表示され、ライブの予約ボタンも出ません）

## ライブ予約
キーを設定すると、これからのライブすべてに「予約する」ボタンが付きます。
- ボタンを押すと `/reserve/` が開き、その公演が選択済みになります
- 予約はお問い合わせと同じメールに件名「【予約】12/20(日) 公演名 @会場」で届きます（Gmailなら件名で検索・ラベル分けすると公演ごとに集計しやすい）
- 予約を受け付けない公演は、ライブのファイルに `reserve: false`（Pages CMS では「サイトで予約を受け付ける」のチェックを外す）
- 外部のチケットサイトがある公演は `ticket_url` を入れると「チケット購入」ボタンも並びます
- 終わった公演は翌日に自動で予約一覧から消えます
- ※予約者への自動返信メールは Web3Forms の有料機能のため、確認の返信は手動でお願いします

## SNS への自動投稿（任意）
`https://(サイトURL)/feed.xml` が RSS です。IFTTT や Zapier などの「RSS → X / Facebook 投稿」連携に登録すると、ニュースを書くだけで SNS にも告知できます。

## 公開手順（初回のみ）
1. GitHub で新しいリポジトリ（例：`inohara-jun-web`）を作り、このフォルダの中身をルートに置く
2. Settings → Pages → Source を **GitHub Actions** にする（`.github/workflows/pages.yml` が自動でビルド・公開）
3. 独自ドメインを使う場合：Settings → Pages → Custom domain に `www.inohara-jun-web.com` を入力し、ドメイン管理会社の DNS に CNAME（`<ユーザー名>.github.io`）を設定
   - 現在のサービスでドメインを取得している場合は、ドメインの移管または DNS 設定変更が必要です
