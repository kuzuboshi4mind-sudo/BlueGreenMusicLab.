# レッスン帳(汎用版)

音楽講師のための、月間スケジュール・生徒・月謝・年間回数の管理アプリ。
本人用に作り込んだ「レッスンスケジュール」(kuzuboshi4mind-sudo/lesso-schedule)を土台に、
特定の人に依存する部分を外して、どの講師でも使えるようにした版。

HTML / CSS / JavaScript だけで動く(ビルド不要)。`index.html` を開けば動く。

## 元のアプリから引き継いだ機能
- 月の表(縦=30分刻みの時刻、横=日付)。土日・祝日・年末は水色、今日は黄色。スマホは1日表示
- 状態:仮・確約・欠席(消化)・キャンセル・なし(自分の予定)。仮の月の印
- 種類(場所)ごとの色分けと、月の時間数の集計(換算表は設定で変更)
- くり返しの固定枠(毎週・毎月 第n○曜日・最終○曜日・毎月○日)と「この日だけ」の変更・休み
- 生徒メモ、「連絡が必要/返事待ち/確定済み」のまとまり、前月の生徒で未入力の人
- 仮の予定を LINE で送る → 返事が来たらまとめて確定
- 長押しでマスを選択・コピー・貼り付け、元に戻す(50回)、ゴミ箱(30日)
- バックアップ(.json)、Excel 形式(.xlsx)への書き出し
- ログインとクラウド保存(Supabase)。電波がないときは端末の写しを読むだけで表示

## 汎用化した部分(元は本人専用だったもの)
| 元 | 汎用版 |
|---|---|
| 種類の初期値(OKI川口・JINIS・サウナ・釣りなど) | 自宅教室・スクール・グループ・出張・訪問・オンライン・練習・本番・ライブ・その他(設定で自由に変更) |
| JINIS だけ曜日で色が変わる | 種類の `weekdayColors` があるときだけ(初期値はなし) |
| 「Numbers と同じ色にする」 | 「初期の色に戻す」 |
| 「Numbers に書き出す」「OKI川口・OKI加茂だけ」 | 「Excel 形式で書き出す」。書き出す種類をチェックで自由に選べる |
| メモアプリ(本人の Firebase)とつなぐ | 外した(`js/memo-link.js` は何もしない部品) |
| 本人の Supabase の接続先(`config.js`) | 空にした(この端末の中に保存。販売時に接続先を入れる) |
| 名前「レッスンスケジュール」 | 「レッスン帳」 |
| (なし) | 設定に「教室の情報」(教室名・講師名)。LINE の文面と月謝のお知らせの {教室}・{講師} に入る |

## 追加した機能
### 月謝(上の「月謝管理」→「月ごとの月謝」)
- 生徒ごとに料金を決める(生徒の画面の「料金と年間回数」):**月謝(毎月定額)/1回ごと/なし**、金額
- 月ごとの一覧:料金、消化した回数、請求額、入金
  - 請求額は自動で計算(月謝=そのまま、1回ごと=「確約+欠席(消化)」の回数×金額。仮とキャンセルは数えない)
  - 金額の欄に入れると、その月だけ手入力の金額にする
  - 「未入金/入金済み」をタップで記録(入金日=今日)
  - 上に「請求の合計・入金済み・未入金」
- 「お知らせ」:月謝のお知らせの文面(レッスン日・回数・請求額・教室名)を作り、コピーか LINE で送る
- 上の「月謝管理」ボタンの数字:**先月分**で、まだ入金していない人数

### 年間回数(上の「月謝管理」→「年間回数」、生徒の画面)
- 生徒ごとに「年間の回数」(例:年間40回)と「年度の始まり」(例:4月)を決める
- 年度ごとに数える:**消化**(今日までの確約・欠席)、**確約の予定**(これから)、**仮**、**まだ入れていない回数**
- 棒グラフと、年度の日数で割った「今日までの目安」の線。目安より何回先・遅れか
- 注意:確約が年間回数を超えた/仮まで入れると超える/残りの週より残りの回数が多い

### データの持ち方
- 料金と年間回数:設定の `studentExtras[名前].plan`(名前の変更・バックアップに自動で付いてくる)
- 入金の記録:設定の `payments`(`{ 'YYYY-MM': { 名前: { paid, paidDate, amount } } }`)。名前の変更で引き継ぐ
- 教室の情報:設定の `profile`
- どれも設定(`user_settings`)の1項目なので、データベースの表は増やしていない。「戻す」で元に戻せる

### カレンダーと同期(設定 →「カレンダーと同期」)
- 同期する先を選べる:**スマホのカレンダー**(iPhone・iPad・Mac)/**Google カレンダー**(Android も)。両方も可
- 入れる予定(確約だけ / 確約と仮)、通知(なし・10分前・30分前・1時間前)、生徒の名前を出すか、自分の予定も入れるか を選べる
- クラウド保存のとき:「同期をはじめる」で購読用の URL を作り、「スマホのカレンダーに追加」「Google カレンダーに追加」で追加する。
  予定を変えるたびに(3秒まとめて)自動で送り直す。カレンダー側の更新間隔は iPhone=設定で変えられる、Google=数時間〜1日
- どちらのときも:「.ics ファイルを書き出す」で1回だけ取り込める
- このアプリ → カレンダーの一方向(カレンダー側で直しても戻らない)。30日前〜200日先の予定を出す

### 表計算アプリに書き出す(設定 →「表計算アプリに書き出す」)
- 開くアプリを選ぶ:**Excel / Numbers / Google スプレッドシート**(選んだアプリでの開き方を案内する)
- 形式:**色つきの表(.xlsx)**(月ごとの表+「予定の一覧」+「月謝」のシート)か **予定の一覧(.csv)**(Excel で文字化けしない形)
- 種類をしぼって書き出せる(スクールに出す分だけ など)

### アカウント(1つのクラウドに複数の講師)
- ログイン画面に「新規登録」「パスワードを忘れたとき」。確認メール・再設定メールのリンクからアプリに戻る
- 講師ごとのデータは RLS(行単位のアクセス制限)で分かれる(どの表も「その講師の行だけ」)

## クラウドの準備(販売する人が1回だけ行う)
1. supabase.com で新しいプロジェクトを作る(地域は Tokyo)
2. SQL Editor で `supabase/schema.sql` を全部貼り付けて Run(何度実行しても壊れない)
3. Authentication → Sign In / Providers:**「Allow new users to sign up」をオン**、Email の「Confirm email」をオン(確認メールを送る)
4. Authentication → URL Configuration:Site URL と Redirect URLs に公開する URL(例:`https://lessonbook.example.com/`)を入れる
5. Authentication → Emails:確認メール・再設定メールの文面を日本語にする(必要なら独自の送信元 SMTP を設定。無料の送信は1時間あたりの数が少ない)
6. カレンダーの同期:Supabase CLI で `supabase functions deploy calendar-feed --no-verify-jwt`
   (`supabase/functions/calendar-feed/index.ts`。カレンダーアプリはログインできないので、JWT の確認を切り、token で見分ける)
7. `config.js` に Project URL と Publishable key を入れる(秘密のキーは入れない)

## これから(販売に向けて)
- **月額制の課金**(決定済み):Stripe の「サブスクリプション」を使う予定。
  無料のお試し期間 → Stripe の支払い画面(Checkout)→ 支払いの状態を Supabase の表に記録(Stripe からの知らせを受ける Edge Function)→
  支払いが止まったら「見るだけ」にする、の順に作る。Stripe のアカウント(本人確認・入金口座)が必要
- 利用規約・プライバシーポリシー・特定商取引法の表記のページ(ログイン画面の同意のチェックからつなぐ)
- 休み・振替の規定を設定に書いておき、生徒に送れるようにする
- 請求書・領収書の PDF
- Google カレンダーとの双方向の同期(Google の審査が必要なため、今は一方向)
