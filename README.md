# タップ召喚

スマホで遊べるミニゲーム。画面をタップしてコインを集め、キャラを召喚して仲間を増やそう。

## 遊び方
- **タップ**：画面をタップするとコインがたまる（マルチタッチ対応、指の本数ぶんカウント）
- **フィーバー**：連打でゲージがたまると8秒間コイン3倍
- **召喚**：コインを使ってキャラを召喚（1回 / 10連はSR以上1体確定＋1割引）
- **仲間**：仲間が増えるほど1タップで得られるコインが増える。同じキャラが出るとレベルアップ
- **図鑑**：集めた仲間を確認できる（全18種、N / R / SR / SSR）

データはブラウザ（localStorage）に自動保存されます。

## 起動方法
`index.html` をスマホのブラウザで開くだけ（ビルド不要・1ファイル完結）。
GitHub Pages で公開すれば URL からすぐ遊べます。

# 正捕手争い（勝敗メモ）

`seihoshu/index.html` を開くだけで使える勝敗メモアプリ。

- 対戦ごとに **A・Bの名前** を自由に入力（過去の名前は候補に出る／前回の名前を自動入力）
- **点数は手入力**。点数が **高い方が負け**、同点は引き分け
- 記録すると **勝敗記録の表** に追加され、新しい順に残っていく（行ごとに削除可）
- 名前ごとの **通算成績**（勝・敗・分・勝率）を自動集計
- CSVで書き出し可能。データはブラウザ（localStorage）に保存
- **ホーム画面に追加してアプリとして使える**（PWA対応・オフラインでも起動可）

### スマホのホーム画面に追加する
GitHub Pages などで公開した `…/seihoshu/` のURLをスマホで開き、
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー（︙）→「ホーム画面に追加」／「アプリをインストール」

※ ホーム画面から開いたアプリの記録は、ブラウザで開いたときの記録とは別に保存されます（特にiPhone）。

# レッスン帳（音楽講師向けレッスンスケジュール管理）

`lesson/index.html` を開くだけで使える、個人で教える音楽講師向けのスケジュール管理アプリ。
教室名・講師名は設定画面で変更でき、特定の教室に依存しない汎用版として作っています。

### 主な機能
- **スケジュール**：日表示（週ストリップ＋その日の一覧）／週表示／**月表示**（日付を横・時刻を縦に並べた月間の時間割。今日の列へ自動スクロール、空き時間タップで追加）
- **日付メモ・一括休講**：日付に「発表会」「祝日」などのメモ。台風・講師都合の日はその日の予定をまとめて休講に
- **繰り返し登録**：毎週・隔週でまとめて登録、削除は「この回のみ／以降すべて」を選択
- **時間の重複チェック**：他のレッスンと重なると警告
- **状態管理**：予定／実施済／欠席(振替あり)／欠席(振替なし)／休講(講師都合)
- **欠席の振替判定**：連絡を受けた日を入れると、期限（初期設定はレッスン3日前まで・設定で変更可）内なら振替あり、期限後・連絡なしは振替なし（1回受講扱い）と自動判定。特例での変更も可
- **振替管理**：振替ありの欠席と講師都合の休講は「振替待ち」として生徒ごとに表示し、振替レッスンと紐づけ。休講で振替できない場合は「振替しない」で翌月の月謝から1回分を返金
- **生徒管理**：楽器・コース、色分け、料金（月謝／1回ごと）、保護者・連絡先、メモ、休会
- **レッスン記録**：回ごとに内容・宿題を記録、生徒ごとに履歴表示
- **月謝管理**：月ごとに請求額を自動計算（手入力で上書き可）、休講返金の差し引き、入金チェック、生徒ごとの明細と「レッスン料のお知らせ」文のコピー、CSV書き出し
- **連絡文コピー**：テンプレートから「次回のレッスンは〜」の文面を作成しLINE等に貼り付け
- **カレンダー連携**：.ics 書き出しで Google / iPhone カレンダーに取り込み
- **バックアップ**：JSONで書き出し・復元。サンプルデータで動作確認も可能
- PWA対応（ホーム画面に追加・オフライン動作）。データは端末内（localStorage）のみに保存

### 請求回数の考え方（1回ごと料金の場合）
休講と振替ありの欠席は数えず、その振替レッスンを行った回で数えます。振替なしの欠席は請求対象です。
月謝の場合は「月のレッスン回数」から1回あたりの金額を出し、講師都合で振替できなかった回を翌月の月謝から差し引きます。
