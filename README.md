# タップ召喚

スマホで遊べるミニゲーム。画面をタップしてコインを集め、キャラを召喚して仲間を増やそう。

## 遊び方
- **タップ**：画面をタップするとコインがたまる（マルチタッチ対応、指の本数ぶんカウント）
- **フィーバー**：連打でゲージがたまると8秒間コイン3倍
- **召喚**：コインを使ってキャラを召喚（1回 / 10連はSR以上1体確定＋1割引）
- **仲間**：仲間が増えるほど1タップで得られるコインが増える。同じキャラが出るとレベルアップ
- **図鑑**：集めた仲間を確認できる（全18種、N / R / SR / SSR）

データはブラウザ（localStorage）に自動保存されます。

## 起動方法
`index.html` をスマホのブラウザで開くだけ（ビルド不要・1ファイル完結）。
GitHub Pages で公開すれば URL からすぐ遊べます。

# Voice Lab（ボイストレーニング）

`voice-training/index.html` をブラウザで開くと起動します（ビルド不要）。
マイクを使う練習は HTTPS（GitHub Pages など）か localhost で開いてください。

## 構成
- **初期設定**：性別・年齢・経験・最高音／最低音を入れると「あなた向けメニュー」がデフォルトに。目安の自動入力やマイクでの音域測定も可能。ホームでいつでも「ノーマルメニュー」に切り替え可能。
- **ホーム**：音感／呼吸／ロングトーン／構音（母音・子音・滑舌）／ストレッチ／図解／テスト（現在は音感のみ実装、他は準備中）
- **音感トレーニング**
  - 高低判定：適応型で「聴き分けられる音の差（セント）」を測定
  - 音程当て：短2度〜完全8度。連想曲つき
  - ピッチマッチ：お手本と同じ高さで発声し、チューナーで判定。高め／低め傾向をアドバイス
  - スケール発声：5トーン・アルペジオなどを半音ずつ移調して歌う
  - チューナー／音域チェック：測った音域をそのまま設定に保存

あなた向けメニューでは、音域の端を避けた練習音域・経験に応じた判定の厳しさ／テンポ・年齢（子ども／変声期／シニア）に応じた調整が自動で入ります。
